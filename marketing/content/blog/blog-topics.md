## Content Production Notes

- All blog posts should be bilingual (English + Hebrew)
- Include at least 3 original photos per post
- End every post with a clear CTA (book, estimate, WhatsApp)
- Use H2/H3 structure for SEO
- Include internal links to tour pages, booking form, and estimator
- Optimize meta description for each post
- Add schema markup for FAQ sections where applicable
