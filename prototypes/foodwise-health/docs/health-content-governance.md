# FoodWise Health: กติกาข้อมูลสุขภาพ

เอกสารนี้กำหนดขอบเขตข้อมูลของต้นแบบ FoodWise Health ซึ่งเป็นเครื่องมือช่วยอธิบายการเลือกอาหารตามภาวะสุขภาพ ไม่ใช่ระบบวินิจฉัยโรค ไม่ใช่การสั่งรักษา และไม่ควรแทนการประเมินของแพทย์หรือนักกำหนดอาหาร

## ขอบเขตข้อมูลเกาต์ในรุ่นแรก

| หัวข้อ | หลักการที่ใช้ในต้นแบบ | การแสดงผลในผลิตภัณฑ์ |
| --- | --- | --- |
| เครื่องใน | จัดเป็นกลุ่มพิวรีนสูงที่ควรหลีกเลี่ยง | ไม่ควรกินเลย |
| เนื้อแดงและอาหารทะเลบางชนิด | ควรจำกัดปริมาณและพิจารณาทั้งมื้อ | ควรจำกัด |
| แอลกอฮอล์ โดยเฉพาะเบียร์ | มีความเกี่ยวข้องกับความเสี่ยงและการกำเริบของเกาต์ | ไม่ควรกินเลย |
| อาหารและเครื่องดื่มหวานจัด | ควรจำกัด โดยเฉพาะแหล่งฟรุกโตสสูง | ไม่ควรกินเลย |
| เต้าหู้ ถั่ว ผัก และผลิตภัณฑ์นมไขมันต่ำ | ใช้เป็นตัวเลือกในรูปแบบอาหารสมดุลได้ | กินได้ |
| อาหารที่ไม่มีในชุดกฎ | ห้ามตีความว่าเหมาะสมโดยอัตโนมัติ | ต้องดูส่วนผสมเพิ่ม |

กฎข้างต้นสรุปจากแนวทางอาหารเกาต์ของ Mayo Clinic ซึ่งระบุว่าการปรับอาหารช่วยลดความเสี่ยงของอาการกำเริบได้ แต่โดยทั่วไปไม่ใช่สิ่งทดแทนยาลดกรดยูริกหรือการรักษาที่แพทย์กำหนด [1]  Cleveland Clinic ระบุในทิศทางเดียวกันว่าอาหารพิวรีนต่ำเป็นส่วนเสริมของการดูแล ไม่ใช่วิธีรักษาเกาต์เพียงลำพัง [2]

## กติกาก่อนเพิ่มโรคหรืออาหารใหม่

ผู้ดูแลข้อมูลต้องเพิ่มข้อมูลใหม่เป็น `rule dataset` โดยเก็บอย่างน้อย `condition`, `context`, `food`, `status`, `reason`, `servingGuidance`, `tags`, `confidence`, `source`, `reviewer`, และ `reviewedAt` ทุกกฎต้องมีแหล่งอ้างอิงที่ตรวจสอบได้ วันที่ทบทวน และผู้ตรวจทานที่มีคุณสมบัติเหมาะสมก่อนเปิดใช้กับผู้ใช้จริง

> ห้ามใช้โมเดลภาษาสร้างคำแนะนำทางการแพทย์โดยไม่มีชุดกฎหรือหลักฐานที่ผ่านการตรวจทาน และห้ามทำให้คำตอบที่ข้อมูลไม่พอแสดงเป็น “กินได้” โดยปริยาย

### Trigger → Steps → Human Checkpoint → Failure Path

| องค์ประกอบ | กระบวนการที่แนะนำ |
| --- | --- |
| Trigger | มีการเสนอโรค อาหาร ส่วนผสม หรือหลักฐานทางการแพทย์ใหม่ |
| Steps | รวบรวมแหล่งปฐมภูมิหรือแนวทางองค์กรสุขภาพ, สร้างกฎแบบร่าง, ระบุข้อยกเว้น, เพิ่มชุดทดสอบ, และกำหนดวันที่ทบทวน |
| Human checkpoint | แพทย์ นักกำหนดอาหาร หรือผู้เชี่ยวชาญที่รับผิดชอบทบทวนข้อความทุกส่วนก่อนเผยแพร่ |
| Failure path | หากหลักฐานขัดแย้ง ข้อมูลสูตรอาหารไม่พอ หรือโรคร่วมเปลี่ยนความเสี่ยง ให้แสดง “ต้องดูส่วนผสมเพิ่ม” พร้อมให้ติดต่อผู้เชี่ยวชาญ แทนการคาดเดา |

## สัญญาณที่ไม่ควรให้เว็บแอปตัดสินใจแทน

หากผู้ใช้มีอาการปวดข้อเฉียบพลันพร้อมบวมร้อน อาการแย่ลง มีไข้ หนาวสั่น คลื่นไส้ หรือกินไม่ได้ ควรขอการประเมินเร่งด่วน เพราะอาจมีสาเหตุอื่นที่ต้องดูแล เช่น การติดเชื้อในข้อ [3]
