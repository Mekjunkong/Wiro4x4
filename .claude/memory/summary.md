# Wiro4x4 Project Summary

Wiro4x4 is a bilingual English/Hebrew kosher off-road tour booking website for Chiang Mai, deployed on Vercel.

## Stack

- React 19 + TypeScript + Tailwind CSS 4 + Wouter
- Express + tRPC + Drizzle ORM
- MySQL/TiDB backend
- Vitest test suite

## Current UI Direction

- Brand register: premium adventure, not generic agency.
- Design system: Expedition Dossier, warm parchment surfaces, charcoal text, Temple Gold accents, strong real-photography focus.
- Bilingual Hebrew/English and RTL support are first-class constraints.

## Completed Features / Areas

- Public homepage with hero, product tiers, trust/kosher messaging, social proof, gallery preview, quick WhatsApp quote flow.
- Public gallery with filters, lightbox, user photo upload entry, and real WIRO imagery.
- Tour/package/pricing/reviews/blog/contact/FAQ pages.
- Admin dashboard and operational tabs.
- Authentication/session route work is present in the working tree.
